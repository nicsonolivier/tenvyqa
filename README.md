# TENVYQA

**Atendimento inteligente. Sua barbearia nunca para.**

TENVYQA Business é uma plataforma SaaS criada exclusivamente para barbearias, com atendimento inteligente pelo WhatsApp, gestão de conversas, clientes, barbeiros, serviços, agenda e agendamentos.

## Plataformas

- Web
- iOS
- Android

Todas as plataformas compartilham o mesmo backend, autenticação, banco de dados, agenda e regras de negócio.

## Stack planejada

- React + TypeScript
- Supabase + PostgreSQL
- Supabase Authentication
- Supabase Edge Functions
- OpenAI API
- Meta WhatsApp Business Cloud API

## Princípios

- Produto exclusivo para barbearias.
- Arquitetura SaaS multi-tenant.
- Dados de cada barbearia completamente isolados.
- IA nunca inventa preços, serviços, barbeiros ou horários.
- Banco/backend é a fonte da verdade.
- Chaves de API nunca são expostas no frontend.
- Web e mobile compartilham o mesmo backend.
- Lovable é usado como ambiente de preview; alterações de código devem ser feitas na fonte deste repositório.
