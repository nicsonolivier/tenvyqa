# AGENTS.md

## Regra principal

Este repositório é a fonte oficial da TENVYQA.

- Faça alterações diretamente no código-fonte deste repositório.
- Quando conectado, use Lovable somente para preview/visualização.
- Preserve funcionalidades existentes.
- Antes de mudanças, leia os arquivos relacionados e faça alterações localizadas e seguras.
- Não reescreva histórico Git publicado (sem force push/rebase destrutivo).
- Nunca comite secrets, chaves OpenAI, tokens Meta ou credenciais privilegiadas.
- O produto V1 é exclusivo para barbearias.
- Web, iOS e Android devem compartilhar backend e regras de negócio.
- Toda informação operacional usada pela IA deve ser validada no backend/banco.
